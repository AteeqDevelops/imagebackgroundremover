## 🎯 Simple by Design

The app is built around a straightforward workflow:

```text
        SELECT IMAGE
             ↓
      REMOVE BACKGROUND
             ↓
       PREVIEW RESULT
             ↓
         SAVE / SHARE
```

The goal is to keep background removal simple without unnecessary editing controls or complicated workflows.

---

## 🚀 How It Works

### 01 — Select an Image

Choose an image from your device.

### 02 — Remove the Background

Process the image and isolate the main subject.

### 03 — Preview

Review the resulting image before saving.

### 04 — Save or Share

Save the result or use it wherever you need it.
