## 🎯 Designed to Be Simple

Image Background Eraser focuses on one thing:

> **Remove the background without making the process complicated.**

```text
Select Image
     ↓
Remove Background
     ↓
Preview Result
     ↓
Save / Share
```

---

## 🚀 How It Works

### 01 — Select
Choose an image from your device.

### 02 — Remove
Process the image and isolate the main subject from its background.

### 03 — Export
Save the result as a transparent image and use it wherever you need it.
